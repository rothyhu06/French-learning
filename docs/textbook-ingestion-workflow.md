# 教材 Lesson 可复制录入流程

## 从空白到一节 Lesson

1. 从已核对目录取得候选印刷页范围，不直接视为最终事实。
2. 依据页码映射渲染指定 PDF 页面，逐页确认标题、Unit、印刷页码、重复页和错位。
3. 建立页级取证清单，记录跨页材料、表格、图片、音频/视频标记和无法确认项。
4. 按视觉版块拆分 `source_blocks`，保留原始重音、标点、教材页和核对状态。
5. 由 source blocks 自动生成 `lesson_sections`；普通 Lesson 不需要新增页面组件。
6. 把词汇转成稳定 ID、词性、阴阳性、复数占位和来源页。
7. 把练习分为自动判分与手动完成；没有可靠答案时不创建标准答案。
8. 生成搜索索引、结构化实体与 `content_source_links`，仅 verified 块进入正式搜索。
9. 生成本机私有页面缓存，验证学习/教材双向 URL 和页码。
10. 执行内容、学习闭环、迁移、TypeScript、ESLint 和生产构建检查。

## 人工工作与脚本辅助

仍需人工完成：页面版块判断、法语重音核对、说话人顺序、词性/阴阳性核对、表格关系、题型与答案可靠性判断、跨页边界和版权范围判断。

可由脚本辅助：指定页渲染、页码映射生成、稳定 ID、词汇目录构建、搜索标准化、SQL seed、内容数量统计、页面缓存和回归测试。

最易出错的数据是 PDF 索引与印刷页码、跨页材料、词汇表内部标点、图片题选项关系、听力编号和把开放题误设为自动判分题。

## 对 Leçon 5–10 的适用性

当前结构足以表达普通对话、课文、词汇、语法表、表达、发音、文化、图片练习、音频引用和开放写作。新增普通 Lesson 原则上只需更新教材数据和运行生成脚本，不需要修改页面代码。只有出现目前无法表达的新型交互或教材结构时，才应增加小范围、跨 Lesson 可复用的数据类型。
